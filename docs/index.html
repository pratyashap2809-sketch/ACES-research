ACES — Agentic e-CommercE Simulator

Interactive demo of the sandbox from “What Is Your AI Agent Buying?” (Allouah, Besbes, Figueroa, Kanoria & Kumar, 2025). Original code: mycustomai/ACES.

1 · The mock storefront

Like the paper's mock-app: one search results page, eight products in a 2 × 4 grid, and every attribute under the experimenter's control. Click Randomize scenario to draw a new ACE-BB experiment using the paper's randomization rules (Table 6).

Bars on each card show the selection probability predicted by the paper's conditional-logit estimates (Table 1) for the chosen AI buyer. Prices, ratings and review counts here are illustrative starting values (the paper does not publish the base listings), and the per-product fixed effects θj are not published, so they are set equal. The predictions therefore show how position, tags and attributes move choices, not each brand's true appeal.

Run repeated randomized experiments and record which product the AI buyer picks each time. This mirrors the paper's market-share experiments.

5 · What is a lever worth?

Start from a product chosen 10% of the time and apply one change. Computed from Table 1 with equations (2.1)–(2.2).

“Price headroom” is how much the seller could raise the price and keep the same choice probability: exp(βlever / |βprice|) − 1.

About this page

The paper's real ACES runs a vision-language model in a Selenium browser against a FastAPI storefront (see agent/ and sandbox/ in this repository). That needs model API keys and a server, so it cannot run on GitHub Pages. This page reproduces the storefront and substitutes the paper's fitted choice model for live API calls, so you can explore the findings without any keys. ACE-BBTable 1Table 6Figure 4
